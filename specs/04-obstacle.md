# 지시서 04 · 장애물 앞에서 멈추기

## 목표
초음파로 앞 물체까지 거리를 재며 속도 50으로 전진하다가, 가까운 물체 앞에서 정지·부저 알림을 하고 물체가 멀어지면 다시 출발한다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 앞 물체 거리 측정 | 초음파로 거리를 읽는다. 드라이버가 주는 mm 값을 cm로 환산해 정지·재출발 거리와 비교한다. |
| 거리 표본 수집 | 0.05초 간격으로 측정한다. 최근 유효값 3개를 보관하고 그 중앙값으로 정지·재출발을 판단한다. |
| 처음 유효값 3개가 모이기 전 | 출발하지 않고 네 바퀴를 0으로 유지한다. |
| 0cm 또는 400cm 초과 등 비정상 거리값 | 오류 표본으로 보고 버린다. 중앙값 계산에 넣지 않는다. 연속 1~2회면 이전 주행·정지 상태를 유지한다. |
| 비정상 거리값이 3회 연속 발생 | 네 바퀴를 0으로 멈춘다. 이전 중앙값 표본을 비우고 새 정상값 3개가 모일 때까지 정지를 유지한다. |
| 정상 거리값을 다시 받음 | 연속 오류 횟수를 0으로 되돌린다. 오류 정지 후 새 정상값 3개가 모이면 중앙값으로 거리 조건을 판단해 재개한다. 정지 상태이므로 25cm 이상이어야 재출발한다. |
| 앞으로 이동 | 네 바퀴 속도 50으로 천천히 전진한다. |
| 바퀴 속도를 전달함 | 네 바퀴 명령 사이에 0.01초 간격을 둔다. 속도가 바뀌면 바로 새 값을 보내고, 바뀌지 않아도 0.2초마다 현재 값(정지 0 포함)을 다시 보낸다. |
| 전진 중 물체가 15cm 이내에 들어옴 | 네 바퀴를 0으로 멈추고 삐 소리를 0.2초 한 번 낸다. |
| 장애물 때문에 정지한 뒤 물체가 25cm 이상 멀어짐 | 속도 50으로 다시 앞으로 출발한다. |
| 거리가 15cm 초과·25cm 미만 | 현재 전진·정지 상태를 유지한다. 정지·재출발 기준에 차이를 두어 경계에서 반복 출발·정지하지 않게 한다. |
| 장애물 때문에 정지한 상태가 이어짐 | 멈출 때 낸 부저를 반복해서 울리지 않는다. |
| 아무 키나 Ctrl+C 입력 | 바로 정지한다. |
| 정상 종료 또는 오류 발생 | 네 바퀴 모두 속도 0으로 멈춘다. |
| 종료 정리 | 네 바퀴 정지와 부저·초음파 끄기를 모두 시도한다. 정지 명령을 0.2초 간격으로 3회 보내고, 각 바퀴 사이 0.01초 간격을 유지한다. 일부 명령에서 예외가 나도 나머지를 계속 시도한다. |
| 첫 시험 | 상자 위에서 네 바퀴가 바닥에 닿지 않게 하고, 초음파 앞에 손을 댔다 떼며 정지·삐 소리·재출발을 확인한다. |
| 다음 시험 | 바닥에서 로봇 앞에 상자를 두고 접근 시 정지와 물체가 멀어진 뒤 재출발을 확인한다. |
| 바닥 시험에서 정지 | 자로 로봇 앞 끝에서 상자까지 실제 거리를 재고 초음파 값도 함께 기록한다. |

## 성공 기준 (숫자로)
- 정지 판단 거리: 초음파 기준 15cm 이내. 재출발 판단 거리: 25cm 이상.
- 정지·0.2초 부저 한 번·재출발을 한 묶음으로 1회 성공으로 센다.
- 시험 5회 중 4회 이상 성공하면 통과한다.
- 실제 멈춘 위치는 목표 15cm에서 ±3cm, 즉 12~18cm이면 허용 범위다.
- 실제 거리는 자로 로봇 앞 끝에서 상자까지 잰다. 정지 시 초음파 값과 자로 잰 값을 함께 기록한다.
- 아무 키나 Ctrl+C로 바로 정지하고, 종료·오류 시 네 바퀴 모두 멈춰야 한다.
- 최근 유효값 3개의 중앙값을 사용하고, 첫 유효값 3개 전에는 출발하지 않아야 한다.
- 0cm 및 400cm 초과 값은 판단 표본에서 제외해야 한다. 400cm는 유효 범위에 포함한다.
- 연속 오류 1~2회는 이전 상태 유지, 3회째는 정지해야 한다. 정지 뒤에는 이전 표본을 재사용하지 않고 새 정상값 3개로 거리 조건을 판단해야 한다.
- 속도가 그대로여도 정지 값을 포함해 0.2초마다 네 바퀴 명령을 다시 보내야 한다. 바퀴 사이에는 0.01초 간격을 두고, 종료 시 정지는 3회 반복해야 한다.

## 안전
- 주행 속도: 50. 후진·회피·회전 동작은 추가하지 않는다.
- 이동 범위: 앞 물체 거리 15cm 이내에서 정지, 정지 후 25cm 이상 멀어지면 재출발한다.
- 상자 시험 전에는 네 바퀴가 모두 바닥에 닿지 않는지 사용자에게 확인받는다.
- 바닥 시험 전에는 라즈봇을 바닥에 내려놓고 사방 1m를 비웠는지 사용자에게 확인받는다.
- 바퀴를 돌리는 실행 전에는 매번 사용자에게 묻고 준비됐다는 답을 받은 뒤 실행한다.
- 아무 키나 Ctrl+C로 즉시 정지하고, 오류가 나도 네 바퀴를 모두 0으로 멈춘다.

## 바꿔 볼 값
- 전진 속도: 50.
- 정지 거리: 15cm. 재출발 거리: 25cm.
- 성공 기준: 정지·부저·재출발 한 묶음을 1회로 세어 5회 중 4회 이상.
- 실제 정지 위치 허용 오차: ±3cm. 자로 로봇 앞 끝부터 상자까지 측정한다.
- 부저: 정지할 때 0.2초 한 번.
- 초음파 튐 대책: 최근 유효값 3개의 중앙값을 사용한다. 예를 들어 14·15·200cm이면 15cm로 판단한다.
- 측정 간격: 0.05초. 처음 유효값 3개가 모일 때까지 네 바퀴 정지.
- 유효 거리 범위: 0cm 초과·400cm 이하. 범위를 벗어나거나 읽을 수 없는 값은 중앙값에 넣지 않는다.
- 오류 표본 정책: 1~2회 연속은 이전 상태 유지, 3회 연속은 정지·표본 초기화. 새 정상값 3개가 모이면 거리 조건대로 복구한다.
- 예상 범위를 벗어난 숫자 표본과 별개로, I2C 읽기 실패나 프로그램 예외는 기존 오류 시 정지·정리 규칙을 따른다.
- 바퀴 명령 재전송 주기: 0.2초. 바퀴 사이 간격: 0.01초. 종료 정리 정지 반복: 0.2초 간격 3회.
