# 지시서 02 · 센서 단계별 점검

## 목표
흰 종이 위에서 불빛 색, 손에 따른 거리 숫자, 테이프에 따른 라인센서 값을 차례로 확인한다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 단계별 점검을 요청함 | 기존 tools/sensor_test.py를 --step으로 실행하고 각 단계 전에 준비를 확인한다. |
| 부저·불빛 차례 | 소리와 빨강·초록·파랑·노랑 순서를 관찰한다. |
| 초음파 차례 | 미리 알린 뒤 손을 앞에 댔다 떼며 거리 숫자를 확인한다. |
| 손 움직임과 거리 값의 일치가 불확실함 | 초음파만 선택해 손을 뗀 상태와 가까이 고정한 상태를 따로 측정하고 비교한다. 각 측정 전에 사용자 준비를 확인한다. |
| 라인센서 차례 | 흰 종이 위에서 검은 테이프를 차체 아래 센서 네 칸에 한 칸씩 대며 값과 작은 불 변화를 확인한다. |
| 센서 위치를 확인하고 흰색·검은색을 비교할 때 | 종이는 센서 위에 얹지 않고 바닥에 평평하게 둔다. 흰 부분에서 고정 측정한 뒤 사용자 준비를 확인하고 검은 부분에서 고정 측정한다. |
| 센서 감도 조정을 마쳤다고 사용자가 알림 | 바닥에 놓인 상태에서 흰색과 검은색 값을 다시 읽어 네 칸의 변화를 확인한다. |
| 카메라 차례 | 사진을 저장하고 확인한다. |

## 성공 기준 (숫자로)
- 소리·불빛 순서, 손에 따른 거리 변화, 라인센서 네 칸 각각의 값 변화, 사진을 확인한다.
- 거리 정확도 허용 오차 및 반복 횟수: 미정 — 조원이 정할 질문으로 남긴다.

## 안전
- 바퀴는 움직이지 않는다.
- 단계별 모드에서는 사용자 준비 확인 뒤 다음 단계로 넘어간다.

## 바꿔 볼 값
- 기존 측정 시간과 횟수는 유지하고, 단계 시작 전에 대기한다.
- --only로 부저·불빛(buzzer), 초음파(ultrasonic), 라인센서(line), 카메라(camera) 중 필요한 항목만 선택할 수 있다.
