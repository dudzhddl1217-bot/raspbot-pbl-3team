# 지시서 02 · 줄 따라가기

## 목표
A4에 출력한 폭 2.5cm의 검은 선을 이어 붙인 종이 트랙에서, 라인센서 네 칸으로 직선과 곡선을 따라간다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 주행 시작 | 속도 50부터 시작한다. 바퀴 속도 값은 150을 넘지 않는다. |
| 줄 감지 | 라인센서 값 0을 검은 줄로 판단한다. |
| 가운데 두 칸이 줄을 봄 | 직진한다. |
| 가운데 칸 하나만 줄을 봄(조금 치우침) | 줄이 보이는 쪽으로 꺾는다. 안쪽 바퀴 30, 바깥쪽 바퀴 60. |
| 바깥 칸 하나만 줄을 봄(많이 치우침) | 줄이 보이는 쪽으로 꺾는다. 안쪽 바퀴 0, 바깥쪽 바퀴 60. |
| 네 칸 모두 줄을 놓친 뒤 연속 1초까지 | 마지막으로 꺾던 쪽으로 천천히 찾는다. 안쪽 바퀴 0, 바깥쪽 바퀴 40. |
| 줄을 연속으로 놓친 시간이 1초를 넘음 | 네 바퀴 모두 0으로 멈춘다. |
| 네 칸 모두 검은색 | 일단 직진한다. 이번에는 정지선·결승선 동작을 넣지 않는다. |
| 양쪽에 줄이 보여 방향이 애매함 | 직전 방향을 유지한다. 가운데 두 칸 감지와 네 칸 모두 검은색은 위의 직진 규칙으로 구분한다. |
| 같은 쪽 가운데 칸과 바깥 칸이 함께 줄을 봄 | 중간으로 꺾는다. 안쪽 바퀴 15, 바깥쪽 바퀴 60. |
| 아직 꺾은 적이 없는데 줄을 놓침 | 바로 네 바퀴를 모두 0으로 멈춘다. |
| 줄 놓침으로 멈춘 뒤 다시 줄이 보임 | 자동 재출발하지 않는다. 프로그램을 다시 실행할 때까지 멈춘 상태를 유지한다. |
| 아무 키나 Ctrl+C 입력 | 바로 정지한다. |
| 정상 종료 또는 오류 발생 | 네 바퀴 모두 속도 0으로 멈춘다. |
| 종료 시 정지 정리 | 네 바퀴 0 명령 묶음을 0.2초 간격으로 3회 반복한다. 각 바퀴 사이에는 0.01초 간격을 둔다. 일부 명령에서 예외가 나도 나머지 바퀴와 남은 반복을 모두 시도한다. |
| 상자 시험 전 센서 점검 | 바퀴를 움직이지 않는 센서 점검으로 검은 부분을 한 칸씩 대어 실제 왼쪽부터 센서 값의 대응 순서를 먼저 확인하고 기록한다. |
| 첫 주행 시험 | 센서 순서 확인 후 상자 위에서 네 바퀴가 바닥에 닿지 않게 하고, 센서 아래 종이를 손으로 움직이며 직진·세 단계 꺾기·줄 놓침 탐색·정지를 확인한다. |
| 다음 주행 시험 | 바닥의 종이 트랙에서 실제로 줄을 따라가는지 확인한다. |

센서 해석: 2026-11-03 모터 명령 없는 개별 센서 점검으로 실제 왼쪽부터 x2·x1·x3·x4임을 확인했다. 가운데 두 칸은 x1·x3이다. 상세 기록은 results/2026-11-03-line-sensor-order.txt에 있다.
안쪽·바깥쪽 바퀴: 왼쪽으로 꺾으면 왼쪽 두 바퀴가 안쪽, 오른쪽 두 바퀴가 바깥쪽이다. 오른쪽으로 꺾으면 그 반대다.

## 성공 기준 (숫자로)
- 상자 위 시험에서 종이를 움직인 방향에 맞게 직진·좌우 꺾기가 되는지 사용자가 확인한다.
- 줄을 놓친 뒤 1초까지는 마지막으로 꺾던 쪽을 안쪽 0·바깥쪽 40으로 찾고, 연속 1초를 넘으면 정지해야 한다.
- 꺾은 적 없이 줄을 놓치면 즉시 정지하고, 줄 놓침 정지 후에는 자동 재출발하지 않아야 한다.
- 아무 키나 Ctrl+C를 누르면 바로 정지하고, 종료·오류 시 네 바퀴가 모두 멈춰야 한다.
- 키 정지·Ctrl+C·줄 놓침 종료·오류 종료의 정리 과정에서 네 바퀴 정지 3회 반복과 바퀴 사이 0.01초 간격이 적용되어야 한다.
- 트랙 처음부터 끝까지 손대지 않고 가면 1회 성공이다.
- 바닥 시험 5회 중 3회 이상 성공하면 통과한다.

## 안전
- 시작 속도 50, 최대 속도 값 150.
- 약한 꺾기: 안쪽 30·바깥쪽 60. 중간 꺾기: 안쪽 15·바깥쪽 60. 강한 꺾기: 안쪽 0·바깥쪽 60.
- 줄 놓침 탐색: 안쪽 0·바깥쪽 40. 연속 1초를 넘기면 정지.
- 상자 시험 전에는 사용자에게 네 바퀴가 바닥에 닿지 않는지 확인받는다.
- 바닥 시험 전에는 라즈봇을 바닥에 내려놓고 사방 1m를 비웠는지 확인받는다.
- 아무 키나 Ctrl+C로 즉시 정지하며, 오류가 나도 네 바퀴를 모두 0으로 멈춘다.
- 종료 정리의 정지 명령은 0.2초 간격 3회, 바퀴 사이 0.01초로 보낸다. 읽기 전용 센서 점검은 기존처럼 모터 명령을 보내지 않는다.

## 바꿔 볼 값
- 검은 선 폭: 2.5cm. 트랙에는 직선과 곡선이 있다.
- 시작 속도: 50. 최대 속도 값: 150.
- 약한 꺾기: 30/60. 중간 꺾기: 15/60. 강한 꺾기: 0/60. 탐색: 0/40.
- 줄 놓침 탐색 시간: 1초까지. 1초를 넘으면 정지.
- 성공 기준: 트랙 처음부터 끝까지 손대지 않고 주행, 5회 중 3회 이상.
- 같은 쪽 두 칸은 중간 꺾기. 이전 꺾기가 없으면 줄 놓침 즉시 정지. 줄 놓침 정지 후에는 재실행해야 출발한다.
- 바퀴를 돌리기 전에는 매번 사용자에게 안전 준비를 확인받는다. 센서 순서 확인은 바퀴를 움직이지 않는 읽기 전용 점검으로 먼저 진행한다.
