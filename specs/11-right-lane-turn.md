# 지시서 11 · 마지막 2차선 구간 — 오른쪽 차선으로 내려와 우회전, START선 정지 (담당: 영빈)

> 2026-11-04 초안. 숫자는 **제안값**이며 조가 확정한 뒤 실물 시험으로 맞춘다.
> 시연 코스: 큰 네모 한 바퀴 → START에서 가운데로 → 「천천히」(08, 수현) → 로터리(10, 하은) → **로터리 오른쪽 출구에서 내려오는 두 차선 길(11)** → 우회전 → START선 정지.
> 로터리를 빠져나올 때까지는 10번이 맡고, 11번은 그 뒤부터 맡는다. 기본 주행은 `07_camera_lane.py`(카메라 노란 차선)이고 11번은 그 위에서 「오른쪽 차선 지키기 + 우회전 + START 정지」만 더한다.

## 목표
로터리를 나온 뒤 흰 실선으로 나뉜 두 차선 길에서 **흰 섬 쪽(오른쪽) 차선**을 타고 내려오고, 흰 실선이 끝나는 곳에서 **오른쪽 노란 선을 따라 우회전**한 다음, START 표시(흰 갈매기 무늬)에 닿으면 멈춘다.

## 카메라가 보는 것 (640×480, 07과 같은 띠 120~299행)
- 노란 선 두 줄: 07의 `find_lines()` 그대로 (HSV H 15~40, S 80↑, V 100↑, 좌우 반쪽 평균).
- **흰 실선(차선 구분선)**: 흰색(S 50 이하, V 170 이상) 점 중 두 노란 선 **사이**에 있고, 세로로 띠의 60% 이상 행에 걸쳐 있으며, 너비 40px 이하인 세로 묶음. 흰 섬(너비 큼)·「↙」 화살표(행 비율 낮음)·START 무늬(너비 큼)는 이 조건에서 걸러진다.
- **바닥 흰 비율**: 아래쪽 띠 300~399행에서 두 노란 선 사이의 흰 점 비율. START 갈매기 무늬에 닿으면 크게 오른다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 단계 WAITLANE (시작) | 07 규칙 그대로 차선 가운데를 따라간다. 흰 실선이 **서로 다른 새 화면에서 연속 2회** 보이면 RIGHTLANE로 넘어가고, 그때 오른쪽 차선 폭 = 오른쪽 노란 선 x − 흰 실선 x 를 기억한다. 오른쪽 노란 선이 안 보이면 마지막 07 차선 폭의 절반을 쓴다. |
| 단계 RIGHTLANE (오른쪽 차선 유지) | 차선 중심 = (흰 실선 x + 오른쪽 노란 선 x) / 2. 오른쪽 선만 안 보이면 흰 실선 x + 폭/2, 흰 실선만 잠깐 안 보이면 오른쪽 선 x − 폭/2. 조향은 07의 비례식(기본 35, K 0.4, 0~80) 그대로. 흰 실선이 보일 때마다 폭을 갱신한다. |
| 흰 실선이 끝남 | RIGHTLANE에 1초 이상 있었고 흰 실선이 **0.3초** 넘게 안 보이면 TURNRIGHT로 넘어간다. 두 선이 모두 안 보여도 같다(코너에서 선이 띠를 벗어남). |
| 단계 TURNRIGHT (우회전) | 오른쪽 노란 선이 보이면 중심 = 오른쪽 선 x − 폭/2 로 비례 조향(안쪽 선을 따라 돈다). 오른쪽 선이 안 보이면 **오른쪽으로 호 그리기** 바퀴 (55, 55, 10, 10). 두 노란 선이 다시 보이고 그 폭이 오른쪽 차선 폭의 1.4배 이상이면(큰 길로 나옴) 연속 2회 뒤 FINISHRUN. 4초가 지나도 못 나오면 FINISHRUN로 넘어가되 기록에 「시간 초과」를 남긴다. 2초 넘게 어떤 선도 안 보이면 정지(LOSTSTOP). |
| 단계 FINISHRUN (START로) | 07 규칙 그대로 차선 가운데를 따라간다(차선 폭은 큰 길 폭으로 다시 잰다). 바닥 흰 비율이 **0.25 이상**인 새 화면이 연속 2회면 START로 보고 정지한다. 8초 안에 START를 못 보면 정지하고 「시간 초과」를 남긴다. |
| 단계 STOPPED (끝) | 네 바퀴 0 유지. 삐 0.2초 두 번, 불빛 초록. 프로그램을 다시 실행하기 전엔 재출발하지 않는다. |
| 첫 화면 대기 · 화면 갱신 중단 | 07과 같다: 첫 화면 전 정지, 마지막 새 화면부터 0.5초 넘으면 정지. 같은 화면을 반복해 읽어 새로 본 것으로 치지 않는다. |
| `--check` 실행 | 바퀴 명령을 전혀 보내지 않는다(정지 명령도). 선 위치·흰 실선·흰 비율·단계·계산한 바퀴 값을 1초마다 출력한다. 로봇을 손으로 들고 트랙 위를 옮기며 인식이 맞는지 보는 용도. |
| 화면 표시 · 영상 저장 | 07의 표시에 흰 실선(흰색)·오른쪽 차선 중심·단계 이름·흰 비율을 더해 `results/videos/`에 블랙박스 저장(15fps, 1분 분할, 30개 보관). 글자는 영어·숫자만. |
| 기록 | `results/right_lane_turn_날짜시각.csv`: 경과초 · 화면순번 · 단계 · 왼쪽선_x · 오른쪽선_x · 흰실선_x · 흰실선_너비 · 흰실선_행비율 · 오른쪽차선폭_px · 차선중심_x · 바닥흰비율 · 바퀴값 · 모드. 한 판마다 `results/runs.csv` 한 줄. |
| 아무 키나 Ctrl+C | 즉시 정지하고 종료. |
| 종료 · 오류 | 02/07과 같은 네 바퀴 0 묶음 3회(0.2초 간격·바퀴 사이 0.01초), 부저·불빛 끔, 카메라·녹화 정리. |
| 통합 | `RightLaneController`는 장치 없이 선 위치·흰 실선·흰 비율·시각만 받아 단계와 바퀴 값을 돌려준다. 자동 한 판 프로그램은 로터리(10)가 끝난 뒤 이 판단으로 바꿔 끼운다. 혼자 실행할 때는 로터리 출구에 로봇을 놓고 시작한다(WAITLANE부터). |

## 성공 기준 (숫자로)
- 장치 없는 검증(`tools/test_right_lane_turn.py`): 합성 화면에서 흰 실선 검출(두 노란 선 사이·행 비율·너비 조건, 흰 섬·화살표·START 무늬 제외), 바닥 흰 비율, 단계 전환(연속 2회·0.3초·1초·1.4배·4초·8초·2초 경계), 오른쪽 선 없을 때 호 그리기 값, 정지 뒤 재출발 없음, `--check` 모터 명령 없음, 종료 3회 정지, 영상·CSV 저장.
- `--check`로 로봇을 들고 옮기며: 두 차선 구간에서 흰 실선 x가 오른쪽 노란 선보다 왼쪽에 안정적으로 잡히고, 「↙」 화살표·흰 섬·START 무늬를 흰 실선으로 오인하지 않는다. 10장면 중 9장면.
- 실물(로터리 출구에 놓고 시작): 오른쪽 차선으로 내려와 이탈·손댐 없이 우회전하고 START 무늬 앞 **0~20cm**에서 정지. 5번 중 4번. 정지 뒤 삐 두 번·초록 불빛은 사용자가 눈으로 확인.
- 07의 직선 주행 성능은 그대로여야 한다(WAITLANE·FINISHRUN은 07 판단을 그대로 씀).

## 안전
- 속도는 07과 같다: 기본 35, 바퀴별 최대 80, 절대 한계 150. 우회전 호 그리기는 55/10이며 후진 없음.
- 아무 키나 Ctrl+C로 즉시 정지. 오류가 나도 네 바퀴 0을 3회 시도. 정지(STOPPED·LOSTSTOP) 뒤에는 자동 재출발하지 않는다.
- 바퀴 실행 전 매번 사용자 안전 확인(바닥·사방 1m). 먼저 `--check`로 인식만 보고, 그다음 상자 위, 그다음 바닥.
- 사진·영상은 Git에 올리지 않는다.

## 바꿔 볼 값
- 흰색 기준 S 50 이하·V 170 이상 (조명에 따라 V 150~200). 행 비율 60% ↔ 50%. 너비 40px ↔ 60px.
- 흰 실선 끝 판단 0.3초 ↔ 0.5초. 우회전 호 (55,55,10,10) ↔ (60,60,0,0). 우회전 최대 4초, 큰 길 판단 1.4배.
- START 판단 흰 비율 0.25 ↔ 0.35, 아래 띠 300~399행 ↔ 340~439행(더 가까이에서 정지). FINISHRUN 최대 8초.
- 대안 정지 신호: 라인센서 네 칸이 모두 흰색(1 1 1 1)일 때 — 카메라 판단이 불안정하면 시도.
