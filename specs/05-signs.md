# 지시서 05 · YOLO로 표지 알아보기

## 목표
라즈봇 카메라로 stop sign·person·car 세 종류를 알아보고, 상자와 이름을 그린 영상·사진 및 30장 시험의 맞힌 개수를 남긴다. 바퀴는 움직이지 않는다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 모델 준비 | models/yolo26n_320.onnx를 tools/yolo.py의 Detector(size=320)로 사용한다. |
| 카메라 읽기 | missions/03_video.py의 카메라 스레드처럼 카메라 읽기는 스레드 하나가 맡고, 최신 화면만 보관한다. 기존 open_camera()를 사용한다. |
| YOLO 인식 | 카메라 읽기와 별도 스레드에서 최신 화면을 받아 Detector로 인식한다. 오래된 화면을 대기열에 계속 쌓지 않는다. |
| 인식 대상으로 표시·집계 | stop sign, person, car 세 종류를 대상으로 한다. 인식 점수 0.4 이상을 “알아봤다”로 판단한다. 정답 이름과 같은 대상이 이 점수 이상으로 검출되면 해당 사진을 맞힌 것으로 센다. |
| 결과 화면 | 인식한 물체에 상자와 이름을 그린다. 영상 위 글자는 영어·숫자를 사용한다. |
| 결과 저장 | 원본 사진과 상자·이름을 그린 결과 사진은 results/signs_images/에, 결과 영상은 results/videos/에 저장한다. 두 폴더의 영상·사진은 Git에서 제외하고 정답·거리·각도·인식 이름·점수·맞힘 여부의 기록표만 커밋 대상으로 둔다. |
| 시험 대상 준비 | 인쇄해서 세운 표지판을 쓴다. stop sign 9cm, person 18cm 전신 사진, car 12cm 자동차 사진을 준비한다. |
| 사진 시험 | stop sign 10장, person 10장, car 10장, 총 30장을 찍는다. 표지별로 30cm 4장·50cm 3장·70cm 3장씩 찍는다. 거리마다 정면·왼쪽 비스듬히·오른쪽 비스듬히를 섞는다. 30cm의 네 번째 사진 각도는 사용자가 고른다. |
| 촬영 조작 | 사용자가 표지판을 놓고 엔터를 누르면 그 순간 최신 카메라 화면 한 장을 촬영한다. 촬영 뒤 정답 이름·거리·각도를 물어 기록한다. 찍은 그 화면을 YOLO로 분석해 사진별로 채점한다. |
| 결과 영상 녹화 | 시험 중 상자와 이름을 그린 결과 화면을 15fps H.264 mp4로 녹화한다. 새 결과 화면이 부족하면 마지막 화면을 다시 써 실제 경과 시간과 재생 시간을 맞춘다. |
| 채점·기록 | 사진별 정답 이름·촬영 거리·각도·인식 이름·점수·정답 여부를 기록하고, 종류별 및 전체 맞힌 개수를 센다. |

## 성공 기준 (숫자로)
- 시험 사진은 표지별 10장씩 총 30장이다.
- 인식 점수 0.4 이상을 알아본 것으로 판단한다.
- 30장 중 24장 이상 맞히면 통과한다. 실제 시험은 표지별 10장·거리별 4/3/3장과 각도 섞기 조건을 충족해야 한다.
- 종류별 맞힌 개수를 각각 /10으로, 전체 맞힌 개수를 /30으로 기록한다.
- 결과 사진·영상에 상자와 이름이 보이는지 실제 저장물을 확인한다.

## 안전
- 바퀴는 움직이지 않는다. 모터·서보 동작을 추가하지 않는다.
- models/의 모델과 이름 목록은 변경하거나 삭제하지 않는다. 새 모델이나 큰 패키지를 설치하지 않는다.
- 카메라는 한 스레드에서 읽고 최신 화면을 공유하며, YOLO는 따로 돌린다.
- 영상은 results/videos/에 저장하고 Git에 올리지 않는다(프로젝트 수칙).
- 시험 사진은 results/signs_images/에 저장하고 .gitignore에 넣어 Git에 올리지 않는다.
- 사진 데이터 늘리기는 보류 상태를 유지한다. 이번 시험은 실제 촬영한 30장으로 진행한다.

## 바꿔 볼 값
- 모델: YOLO26n 320. 인식 대상: stop sign·person·car.
- 인식 점수 기준: 0.4 이상.
- 표지별 촬영 거리·장수: 30cm 4장, 50cm 3장, 70cm 3장.
- 각도: 거리마다 정면·왼쪽 비스듬히·오른쪽 비스듬히를 섞는다.
- 대상: 세워 둔 인쇄 표지. stop sign 9cm, person 전신 18cm, car 12cm.
- 합격 기준: 30장 중 24장 이상.
- 결과 영상: 시험 중 15fps. 사진과 영상은 Git 제외, 기록표만 저장소에 올린다.
