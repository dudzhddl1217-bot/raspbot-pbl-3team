# 지시서 03 · 키보드 대각선 조종

## 목표
기존 tools/teleop.py에 숫자패드 배치처럼 7·9·1·3 대각선 이동을 추가하고, 나머지 키와 기존 속도 동작은 유지한다.

## 규칙표
| 상황 (언제) | 행동 (무엇을) |
|---|---|
| 7 입력 | 앞-왼 대각선으로 이동한다. |
| 9 입력 | 앞-오 대각선으로 이동한다. |
| 1 입력 | 뒤-왼 대각선으로 이동한다. |
| 3 입력 | 뒤-오 대각선으로 이동한다. |
| 기존 키 입력 | w/s 앞·뒤, a/d 옆왼·옆오, q/e 제자리 왼쪽·오른쪽 회전을 유지한다. |
| 스페이스 입력 | 네 바퀴를 모두 멈춘다. |
| x 입력 | 네 바퀴를 멈추고 종료한다. |
| 속도 조절 키 입력 | 기존 + 또는 = 올리기, - 또는 _ 내리기를 유지한다. |
| 이동 키 입력이 끊김 | 기존 자동 정지 기준인 마지막 이동 키 입력 후 0.6초를 유지한다. 대각선 키에도 적용한다. |

## 성공 기준 (숫자로)
- 7·9·1·3 네 키가 각각 지정한 대각선 방향으로 움직이는지 사용자가 실제로 확인한다.
- 각 대각선 방향마다 3회 시험해서 3회 모두 지정한 대각선 쪽으로 움직이면 통과한다(총 12회).
- 각 시험에서 키를 떼면 1초 안에 네 바퀴 모두 멈춰야 한다.
- 기존 이동·정지·종료·속도 조절 키와 자동 정지 동작이 유지되는지 확인한다.

## 안전
- 시작 속도는 기존 80을 유지한다. 80 고정으로 바꾸는 것이 아니라 기존 속도 조절 기능도 유지한다.
- 기존 속도 범위 40~150, 조절 간격 20을 유지한다.
- 기존 프로젝트 수칙대로 바닥에 놓고 사방 1m를 비운 상태에서 조종한다.
- 종료 및 오류 발생 시 네 바퀴 모두 속도 0으로 멈추는 처리를 유지한다.
- Codex는 tools/teleop.py를 실행하지 않는다. 사용자가 VS Code 터미널에서 직접 실행한다.

## 바꿔 볼 값
- 추가 키는 7·9·1·3. 나머지 키, 시작 속도 80, 기존 속도 조절 및 자동 정지 기준은 유지한다.
