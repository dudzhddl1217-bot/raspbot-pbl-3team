지시서: specs/02-line.md
프로그램: missions/02_line.py
기본 직진 50, 약한 꺾기 30/60, 중간 15/60, 강한 꺾기 0/60.
줄 놓침 1초까지 마지막 꺾기 방향으로 0/40 탐색, 1초 초과 정지.
꺾은 적이 없을 때 줄 놓침 즉시 정지. 줄 놓침 정지 뒤 자동 재출발 없음.
아무 키·Ctrl+C·오류 시 네 바퀴 0, 정지 명령 하나가 예외여도 나머지 바퀴 정지 시도.

코드 검증: tools/test_line.py의 8개 테스트 통과.
실제 모터 명령 실행: 사용자 안전 확인 후 상자 위 시험을 진행함. 추가 실행 전에도 사용자 확인 필수.
--check-sensors: I2C 라인센서 읽기만 수행, 모터 명령은 정지 명령도 보내지 않음.
실제 개별 센서 순서: 읽기 전용 점검으로 왼쪽부터 x2·x1·x3·x4 확인 완료.
상자 시험: 직진, 좌우 세 단계 꺾기, 탐색과 줄 놓침 정지를 확인하고 사용자도 실제 반응이 맞다고 확인함.
상자 시험 후 사용자 보고: 센서 감도를 바닥 높이에 맞춰 다시 조정함.
조정 후 사용자 센서 확인: 책상 위 흰 부분 1 1 1 1, 가운데 검은 선 0 1 0 1.
이 감도 재조정 결과는 사용자 확인 기록이며 Codex가 센서를 다시 읽거나 주행을 재실행하지 않음.
바닥 트랙 주행 5회 중 3회 성공 기준: 아직 미시험. 전체 주행 합격은 미판정.
