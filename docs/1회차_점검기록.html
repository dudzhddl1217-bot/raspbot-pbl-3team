4. 막혔던 것과 해결

① 바퀴가 안 돎 — I2C 5핀 커넥터가 180° 뒤집혀 꽂힘

증상
motor_test.py에서 write_array I2C error 반복, 삐 소리 없음. SSH에서 0x2b 읽기 → Errno 110 timed out
근거
pinctrl get 2,3: SDA hi, SCL lo(쉬는 상태라면 둘 다 hi여야 함). 커넥터를 빼니 둘 다 hi → 라즈베리파이는 정상, 선이 SCL을 땅에 붙들고 있었음. 보드 RESET으로는 안 풀림
원인
선 정리 때 GPIO 쪽 2×5 커넥터를 뒤집어 꽂음. 커넥터 접점 3개(SDA·SCL 한 줄, GND 한 줄) 중 GND가 SCL 핀에 닿음
해결
전원 끄고 커넥터를 핀 줄 끝(SD카드 쪽) 5칸에, 접점 2개 줄이 안쪽·GND 줄이 바깥쪽이 되게 다시 꽂음 → 보드 응답 OK, 바퀴 4개 정상

② 라인센서가 바닥에서 검은 줄을 못 잡음 — 감도 조정

증상
흰 종이 위에서도 검은 줄 위에서도 1 1 1 1. 로봇을 들어 올리면 검은 줄에서만 센서 불이 켜짐
걸림돌
처음엔 로봇이 상자 위라 센서 밑에 바닥이 없었고, 종이를 카메라 앞에 댔음(센서는 차체 앞쪽 아래, 바닥을 향한 4개)
해결
제조사 문서(Tracking module 2.2)대로 센서 보드의 감도 나사 4개를 돌려 "검은색에서 켜지고 흰색에서 꺼지게" 맞춤 → 흰 1 1 1 1, 검 0 0 0 0. 인쇄한 2.5cm 검은 줄로도 잡힘

③ 카메라가 왼쪽을 봄 — 정면 각도 82°로 확정

증상
기본값 좌우 90°를 보내도 카메라가 왼쪽으로 틀어짐. 서보 자체는 60°↔120°로 크게 움직여 정상
시도
95°(아직 왼쪽) → 100°(더 왼쪽: 방향 반대) → 85°(아주 살짝 왼쪽) → 82°(정면)
해결
짐벌은 다시 끼우지 않고 specs/01-camera-center.md와 servo_center.py, 수칙의 정면 기준을 82°/25°로 고침. 제조사도 "가로 서보 톱니 한 칸 어긋남은 정상"이라 함
